# Together animation

`together.json` is original Konnectivity vector artwork: a shared heart, halos and orbit lights. It contains no external images, fonts or remotely hosted assets. It is rendered with lottie-web (MIT); the runtime license is retained at `docs/third-party/lottie-web-LICENSE.md`. The artwork is distributed with this project under its existing license.

The animation pauses when playback pauses, when the page is hidden, when motion is disabled or when the operating system requests reduced motion.
