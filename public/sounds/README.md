# Konnectivity notification tones

These two short tones are synthesized sine-wave UI assets, generated for the 10.06 source distribution. They contain no music recordings or user audio. They are covered by the repository license.

- `message.mp3`: 660 Hz, 0.18 seconds, fade-out.
- `call.mp3`: 520 Hz, 0.7 seconds, tremolo and fade-out; the client repeats it while ringing.

The browser must first receive a user gesture before notification audio can play. The device notification-sound setting controls these assets.
